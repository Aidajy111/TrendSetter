# Фронтенд онлайн-платформы TrendSetter

Клиентская часть приложения (SPA), разработанная на базе React.js. Отвечает за интерфейс каталога, карточки товаров и модуль виртуальной примерки.

## Предварительные требования
Для локальной разработки у вас должен быть установлен [Node.js](https://nodejs.org/) (версия 18 или выше).

---

## Режим 1: Локальная разработка (Быстрая верстка)
Этот режим идеально подходит для написания UI-компонентов, верстки и отладки логики. В этом режиме работает **Hot Reload** (страница в браузере обновляется сама при сохранении кода).

1. Откройте терминал в папке `/frontend`.
2. Установите зависимости проекта:
   ```bash
        npm install
   ```
3. Создайте файл .env в папке frontend и укажите адрес бэкенда (если локальный Strapi запущен, это будет localhost:4444):
    ```
        REACT_APP_API_URL=http://localhost:4444
    ```
4. Запустите локальный сервер разработчика:
    ```
        npm start
    ```
5. Приложение будет доступно в браузере по адресу: http://localhost:3000

# Режим 2: Работа в общей Docker-среде (Интеграция)
Этот режим используется для проверки взаимодействия всех микросервисов (Frontend + Strapi + Golang + БД) или для финального деплоя на сервер.

В этом режиме фронтенд собирается в оптимизированный Production-билд и раздается через быстрый веб-сервер Nginx.

1. Убедитесь, что вы находитесь в корневой папке всего монорепозитория (там, где лежит файл docker-compose.yml).
2. В корневом файле .env убедитесь, что переменная для API задана верно:
    ```
        REACT_APP_API_URL=http://localhost:4444
    ```
3. Запустите сборку и старт всех контейнеров одной командой:
    ```
        docker-compose up -d --build
    ```

4. Приложение будет доступно в браузере по адресу: http://localhost:3000

Примечание: В Docker-режиме Hot Reload отключен. Если вы внесли изменения в код фронтенда, контейнер нужно будет пересобрать командой docker-compose build client && docker-compose up -d.
