# TrendSetter Try-On Microservice

Изолированный микросервис виртуальной примерки одежды для платформы TrendSetter. Написан на языке Go (Golang). 

Сервис работает по принципу Stateless Worker (не имеет собственной базы данных). Его главная задача — принять фотографию от клиента, передать ее вместе с параметрами одежды во внешнюю нейросеть (GenAPI.ru), дождаться результата, сохранить готовую картинку в Yandex Cloud (S3) и вернуть клиенту публичную ссылку.

## Технологический стек
* **Язык:** Go 1.25.3
* **Фреймворк:** Gin (HTTP веб-фреймворк)
* **Интеграции:** GenAPI.ru API, Yandex Cloud Object Storage (S3)

---

## Переменные окружения (.env)
Для локального запуска создайте файл `.env` в корне папки `go-tryon-service`. В нем должны храниться ключи от внешних сервисов

```env
# Порт, на котором запустится микросервис
PORT=2222

# Ключи для Yandex Cloud S3
YANDEX_S3_BUCKET=trendsetter-media
YANDEX_S3_KEY_ID=your_yandex_key_id
YANDEX_S3_SECRET=your_yandex_secret

# Ключ для нейросети GenAPI.ru
GENAPI_TOKEN=your_genapi_api_token
```

# Режим 1: Локальная разработка (Без Docker)
Используйте этот режим, когда пишете код, настраиваете роуты в Gin или отлаживаете запросы к GenAPI.
1. Убедитесь, что у вас установлен Go.
2. Откройте терминал в папке go-tryon-service.
3. Загрузите все зависимости (библиотеки):
    ```
    go mod tidy
    ```
4. Запустите сервер:
    ```
    go run cmd/main.go
    ```
5. Сервис будет слушать запросы на http://localhost:2222

# Режим 2: Запуск в Docker (Интеграция)
В этом режиме Go-микросервис компилируется в бинарный файл внутри минималистичного контейнера (Alpine Linux) и работает в единой сети с фронтендом и Strapi CMS.

Запуск осуществляется из корневой папки всего проекта командой:
```
docker-compose up -d go-tryon
```
