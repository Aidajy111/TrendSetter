# Strapi CMS — Ядро контента TrendSetter 📦

Этот сервис отвечает за хранение товаров, управление брендами и обработку заказов. Он предоставляет REST API для фронтенда и удобную админ-панель для дизайнеров.

## 🛠 Технологии
* **Фреймворк:** Strapi v5
* **Язык:** Node.js
* **База данных:** PostgreSQL (в Docker) / SQLite (локально)

---

## 🚀 Режим 1: Быстрая разработка (Локально)
Используйте этот режим для создания новых типов данных (моделей) и настройки полей.

1. Перейдите в папку `strapi-cms`.
2. Запустите сервер:
   ```bash
   npm run develop
   ```
3. Админка доступна по адресу: http://localhost:1337/admin
