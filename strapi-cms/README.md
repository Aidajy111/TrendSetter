# Strapi CMS — Ядро контента TrendSetter 📦

Этот сервис отвечает за хранение товаров, управление брендами и обработку заказов. Он предоставляет REST API для фронтенда и удобную админ-панель для дизайнеров.

## 🛠 Технологии
* **Фреймворк:** Strapi v5
* **Язык:** Node.js
* **База данных:** PostgreSQL (в Docker) / SQLite (локально)

---

> ⚠️ **ВАЖНОЕ ПРИМЕЧАНИЕ ПО БАЗЕ ДАННЫХ И ЗАПУСКУ**
> 
> Настоятельно рекомендуется **всегда запускать Strapi в связке с Docker-контейнером базы данных**, даже если вы просто верстаете фронтенд локально. 
> 
> **Почему это важно?**
> По умолчанию локальный запуск (`npm run develop`) использует встроенную файловую БД **SQLite**, а Docker-среда использует **PostgreSQL**. Это две изолированные базы. Если вы создадите пользователя, контент или настройки в локальной SQLite, а затем поднимете проект в Docker, ваши данные "исчезнут" (так как Strapi подключится к пустой PostgreSQL).
> 
> **Best Practice (Лучшая практика):**
> Всегда держите базу данных и CMS запущенными через Docker. Для разработки запускайте из корня проекта команду:
> ```bash
> docker-compose up -d db strapi
> ```
> *(Остальные сервисы, такие как frontend или go-tryon, можно запускать локально через терминал, они будут успешно стучаться к контейнеризированному Strapi).*
