# TrendSetter Frontend

Клиентское веб-приложение для виртуальной примерки одежды. Реализовано на React.js с использованием Vite для быстрой разработки.

## Технологический стек

- **React 18** — библиотека для построения пользовательских интерфейсов
- **Vite** — инструмент сборки и сервер разработки
- **Redux Toolkit** — управление состоянием приложения
- **Tailwind CSS** — утилитарный CSS-фреймворк для стилизации
- **Axios** — HTTP-клиент для взаимодействия с API

## Системные требования

- **Node.js** 20+ (LTS версия)
- **npm** 10+ или **yarn** 1.22+

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск

```
npm run dev
```
После запуска откройте в браузере: http://localhost:5173
